# CRM

Not yet implemented.

Lead sources: website, Instagram, Facebook, Google, WhatsApp, referral,
partner, event, other. Stages: `NEW → CONTACTED → INTERESTED →
APPLICATION_STARTED → APPLICATION_SUBMITTED → PAYMENT_PENDING → CONVERTED /
LOST`. Every lead tracks source, programme of interest, assigned staff,
communication history, status, timestamps.

Note: the unrelated Supabase project connected to this account already has
`crm_contacts`, `crm_deals`, `crm_stages`, etc. — those belong to a different
product (see `database.md`) and are not a starting point for LSSPM's CRM.
