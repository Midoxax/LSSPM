# Vision

**LSSPM** — Ligue des Spécialistes de la Santé Psychique et Mentale (Morocco).
Public site: lsspm.ma. Primary language French; Arabic (RTL) and English planned.

The platform is an institutional operating system, not a marketing site:
public website, admissions, training/formation delivery, finance, CRM,
member/trainer/participant portals, document generation, and workflow
automation, all sharing one `Person` record across roles.

Status: pre-Phase-1. Repository (`lsspm-platform`) currently contains only a
scaffolded Next.js app and a placeholder homepage — no backend, auth, or data
model yet. See `architecture.md` and `database.md` for current vs. proposed
state.
